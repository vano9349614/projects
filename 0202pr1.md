**Учебный файл:** TakeGuidedTour

## 1. Изучение пользовательского интерфейса программы Project

Интерфейс Project построен по аналогии с другими приложениями Microsoft Office и включает панель быстрого доступа, поле «Что вы хотите сделать» (Tell Me), ленту с вкладками, группами и командами, активное представление с меткой, строку состояния, ярлыки представлений и ползунок масштаба.

1. Запущена программа Project, открыт план TakeGuidedTour (File → Open).
2. Указатель мыши наведён на одну из команд ленты (например, на кнопку связывания задач на вкладке Task). Появилась экранная подсказка (ScreenTip) с кратким описанием команды и сочетанием клавиш.
3. С помощью ползунка масштаба в правом нижнем углу строки состояния масштаб был увеличен несколько раз. Шкала времени диаграммы Ганта стала более детальной: от кварталов и месяцев к неделям и дням.
4. Выполнен щелчок правой кнопкой мыши по названию одной из задач. Появились мини-панель инструментов и контекстное меню с командами вырезания, копирования, вставки, добавления и удаления задачи, назначения ресурсов, просмотра сведений и примечаний.

## 2. Управление файлами и настройка параметров в представлении Backstage

Представление Backstage открывается щелчком по вкладке File и содержит основные команды управления файлами: Info, New, Open, Save, Save As, Print, Share, Export, Close, а также Account и Options.

1. В Project открыт план TakeGuidedTour.
2. На вкладке File выбрана команда Save As (Сохранить как).
3. Выполнен переход в папку с учебными файлами.
4. В поле File Name введено уникальное имя учебного файла и нажата кнопка Save. Файл сохранён под новым именем, исходный план не изменён.

## 3. Работа с деталями расписания в представлениях

Представления позволяют рассматривать один и тот же набор данных плана с разных сторон: сосредоточиться на задачах, ресурсах или назначениях. Для переключения используются кнопки в группах Task Views и Resource Views на вкладке View, а также команда Other Views.

1. Открыто представление Resource Sheet (Лист ресурсов): View → Resource Views → Resource Sheet. Информация о ресурсах плана представлена таблицей, где одна строка соответствует одному ресурсу.
2. Выполнено переключение в представление Calendar (Календарь): View → Task Views → Other Views → Calendar. Представление показывает задачи плана по дням, неделям и месяцам и удобно для просмотра всего месяца.

## 4. Использование отчётов для проверки состояния плана

Отчёты отображают данные проекта в удобочитаемом виде и могут содержать диаграммы, таблицы и изображения. Просмотр отчётов выполняется на вкладке Report в группе View Reports.

1. Открыт отчёт Project Overview (Обзор проекта): Report → Dashboards → Project Overview.
2. Выполнен переход к отчёту Resource Overview (Обзор ресурсов): Report → Resources → Resource Overview. Отчёт содержит диаграммы фактической, оставшейся и базовой трудоёмкости ресурсов, процент выполненной работы и таблицу оставшейся работы.
